# SVG 시작 잔선·마그네틱 수직 추적 수정

검증일: 2026-10-17. 검증한 수정 커밋: [b270fae](https://github.com/leejh96/vibe-dictionary/commit/b270faebb40a1532647c803d9a0937872798fe56). [PR #3](https://github.com/leejh96/vibe-dictionary/pull/3)으로 병합·배포했다. 아래는 당시 결과이며 현재 실행 결과를 대신하지 않는다.

## 원인과 결정

- SVG: 임의 도형에 고정 dash 320을 적용하면 실제 경로가 더 길 때 시작 잔선이 남았다. 데모와 복사용 프롬프트에 `pathLength="1"` 정규화를 적용하고 CSS dasharray·초기 dashoffset을 1로 맞췄다. 2.4초 루프와 65% 그리기·85% 채움 완료 조건은 유지했다.
- 마그네틱: X 오프셋 0을 이탈로 판단해 수직 이동·중심 통과에서 450ms 복귀 곡선을 사용했다. 좌표와 별개로 추적 상태를 기록해 모든 mousemove에 50ms ease-out을, mouseleave에 오프셋 초기화와 450ms 탄성 복귀를 적용했다.

외형·SaaS 모션·다른 기법·조합기는 이 수정 범위에 포함하지 않았다. 변경 구현과 프롬프트는 PR diff, 유지되는 회귀 검증은 [데모 동작 테스트](../../../tests/demo-behavior.test.tsx)에서 확인할 수 있다.

## 당시 검증 결과

- `npm test` 12개 통과, `npm run build` 통과. 새 회귀 테스트는 수직 이동 → 중심 통과 → 대각선 → 이탈 → 재진입의 오프셋과 전환 시간을 확인했다.
- 실제 데모와 프로덕션 CSS를 360×160px 프레임에서 실행하고 브라우저 검사 19개가 통과했다. 수정된 SVG 프롬프트는 원본·이전 결과를 보지 않은 새 에이전트가 한 번 생성했으며 비교 후 수정하지 않았다.

| 관찰 대상 | 결과 |
| --- | --- |
| 이전 SVG 생성본 | 실제 길이 332.42, dash 320. 시작 외곽선 픽셀 74개 |
| 수정 사이트 SVG | 실제 길이 292.60, pathLength 1. 시작 외곽선 픽셀 0개 |
| 수정 프롬프트 독립 생성본 | 실제 길이 409.93, pathLength 1. 시작 외곽선 픽셀 0개 |
| SVG 65%·85%·90% | 수정 데모·생성본 모두 그리기 완료와 fill alpha 0.25 유지 확인 |
| 마그네틱 수직·중심·대각선 | 42% 오프셋, 중심에서도 50ms 추적 유지 |
| 마그네틱 이탈 | 오프셋 0, 450ms cubic-bezier(0.34,1.56,0.64,1) |

픽셀 수는 실제 path의 계산된 스타일·좌표·pathLength를 Canvas로 직렬화해 alpha > 8/255로 집계한 값이다. 화면 캡처에서도 이전 생성본의 시작 잔선을 확인했다. 마그네틱은 합성 이벤트와 계산된 CSS를 검사했고, 비활성 iframe의 전환 지연 때문에 전환을 완료시킨 뒤 최종 좌표를 확인했다. 전환 시간은 CSS 값이며 벽시계 재생 시간 측정은 아니다.

## 한계와 자료 보관

독립 생성은 한 번이며 단일 프레임 크기·다크 테마 중심이다. 모든 도형·모델·뷰포트의 성공이나 터치·라이트 테마·전체 카탈로그 재현을 보장하지 않는다.

전체 실행 기록과 원시 자료는 Git에서 제외되는 `docs/local/`에 로컬 보관한다. 재검증할 때는 현재 코드·자동 테스트와 해당 입력 조건을 다시 확인한다.
