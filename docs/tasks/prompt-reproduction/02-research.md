# 5개 프롬프트 독립 재현 실험

검증일: 2026-10-17. 원본 기준: [14dd984](https://github.com/leejh96/vibe-dictionary/commit/14dd9840f1eb54a5b333544ac56a114b9fbe763e). 과거 실험 기록이며 현재 검증 결과를 대신하지 않는다.

## 목적과 방법

사이트의 복사용 프롬프트만으로 의도한 효과를 구현할 수 있는지 확인했다. 각 도메인의 첫 항목을 하나씩 미리 선택하고, 원본 코드·이미지와 이전 대화를 보지 않은 별도 에이전트 5개에 하나씩 전달했다. 최초 생성본을 비교 후 수정하거나 결과를 교체하지 않았다.

공통 조건은 외부 라이브러리 없는 HTML/CSS/JS와 360×160px 프레임이었다. 원본 React 데모와 실제 프로덕션 CSS를 사용해 입력·DOM·계산된 스타일을 비교했다. 애니메이션은 지정 시점에 고정하거나 테스트 시계를 사용했으며 실제 벽시계 재생 속도 측정은 아니다. 원본은 다크 테마였고, 프롬프트에 없는 외형은 생성자가 결정했다. 정확한 API 모델 식별자는 수집하지 않았다.

## 관찰과 해석

기본 검사는 44/45개 통과했다. 마그네틱 수직 입력은 이 집계에 포함하지 않은 추가 검사다. 통과 수는 검사 단위를 나눈 결과이며 시각 유사도나 전체 카탈로그의 성공률이 아니다. 5개 모두 의도한 효과를 확인했지만, 색·문구·치수·도형과 일부 모션 곡선에는 차이가 있었다.

## 결정과 후속 처리

- 사용 목적은 **효과와 상호작용 재현**으로 확정했다. 별도 요구가 없는 외형 차이를 오류로 취급하지 않는다. 현재 기준은 [프롬프트 품질 기준](../../prompt-quality.md)에 정리했다.
- SVG는 임의 도형과 고정 dash 길이의 관계가 불명확했다. 마그네틱은 원본이 X 좌표 0을 이탈 상태로 판단했다. 두 문제는 [PR #3](https://github.com/leejh96/vibe-dictionary/pull/3)에서 수정했고, 결과는 [수정 검증 기록](../svg-magnetic-fix/verification.md)에 남겼다.
- SaaS의 키프레임·easing과 외형 차이는 위 목적에서 추가 수정하지 않았다. 원본의 모든 프레임을 복제한다는 요구로 해석하지 않는다.

## 한계와 자료 보관

표본은 5개·각 1회다. 전체 122개, 기법 조합, 반복 생성 성공률, 다른 모델·뷰포트·테마·터치·접근성 전반은 검증하지 않았다. 픽셀 유사도 점수도 산출하지 않았다.

원시 보고서·생성 HTML·측정 JSON·스크린샷은 Git에서 제외되는 `docs/local/prompt-reproduction/`에 로컬 보관한다. 저장소에는 이 요약만 포함하므로 새로 복제한 환경에 실험 도구와 원본 자료는 제공되지 않는다.
