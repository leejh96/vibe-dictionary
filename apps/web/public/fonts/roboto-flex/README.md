# Roboto Flex — VIBE subset

- Source: [Google Fonts Roboto Flex](https://github.com/google/fonts/tree/main/ofl/robotoflex).
- Downloaded 2026-10-18 using the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Roboto+Flex:wght@400..1000&text=VIBE&display=swap). The downloaded WOFF2 contains a `wght` axis from 100 to 1000 (default 400), verified from its OpenType `fvar` table.
- Only `B`, `E`, `I`, `V` are included. The proximity and cylindrical typography demos share this asset; it is not a general UI font.
- Copyright 2017 The Roboto Flex Project Authors. The original [SIL Open Font License 1.1](OFL.txt) accompanies the font and is copied into the web build with it.
- The browser loads the local asset. There is no runtime Google Fonts dependency.
